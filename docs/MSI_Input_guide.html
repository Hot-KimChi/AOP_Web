MSI input 사용 설명서

엑셀로 정리한 RTP 조건을 불러와 고르고 다듬은 뒤, 측정 조건(meas_setting)과 온도 조건(temp_setting)으로 데이터베이스에 저장하는 화면입니다. 이 문서는 처음 쓰는 사람도 순서대로 따라 할 수 있게 작성했습니다.

1. 한눈에 보기

무엇을 하나요?

엑셀의 RTP 행을 골라 초점(Foci)·조리개 값을 다듬고, 측정 조건 ID(measSetId)를 만들어 DB에 저장합니다.

준비물

① AOP Web 로그인 ② 작업할 데이터베이스 ③ 내 PC에 있는 RTP 엑셀 파일(.xlsx·.xls·.csv, 20MB 이하)

결과물

DB의 meas_setting(Tank·Power), temp_setting(Temp) 행, 그리고 필요하면 내려받는 -Sel.xlsx·MeasInput_날짜.txt 파일
핵심 흐름 — 파일 열기 → 행 고르기 → 값 다듬기 → Save … to DB. 저장 버튼을 누르기 전까지는 DB에 아무것도 기록되지 않습니다.

2. 화면 여는 방법

  1. MeasSet Generation 메뉴 → MSI input 탭

    상단 메뉴에서 MeasSet Generation을 열고 MSI input 탭을 누릅니다.

  2. Database 선택

    MsiChoice 카드 안의 Database 목록에서 작업할 DB를 고릅니다. DB를 고르기 전에는 버튼이 비활성입니다.

  3. MSI Input From Excel 클릭

    measSetInput 화면이 새 브라우저 창으로 열립니다. 창 크기에 맞춰 화면 전체가 한 페이지에 보이도록 자동으로 확대·축소됩니다.
창이 열리지 않으면 브라우저가 팝업을 막은 것입니다. 주소창 오른쪽의 팝업 차단 아이콘에서 이 사이트의 팝업을 허용해 주세요.

참고: 옆의 MSI Input From Dumped Data는 덤프된 검증 데이터에서 MSI를 만드는 별도 기능으로, 이 문서에서는 다루지 않습니다.

4. 단계별 사용법 (Tank·Power 저장)

  1. 엑셀 파일 고르기

    Excel File Directory 입력칸을 더블클릭하면 폴더 선택 창이 뜹니다. 엑셀이 들어 있는 폴더를 고르면 아래 목록에 파일 이름이 나타납니다. 목록에서 파일을 한 번 클릭해 선택합니다.
    웹에서는 서버가 아니라 지금 쓰는 PC의 폴더를 읽습니다. 네트워크 드라이브(예: R:\Compass\ExcelFile)도 PC에 연결되어 있으면 고를 수 있습니다.

  2. Open Excel File

    선택한 파일이 서버로 올라가 표로 변환되고, ② Exel Input 표에 표시됩니다. 이 단계에서는 DB에 아무것도 저장되지 않습니다.

  3. 저장할 행 고르기

    • 한 행씩: Exel Input에서 행 맨 왼쪽 칸(행 머리글)을 더블클릭하면 ③ Selected RTP에 추가됩니다.
    • 한꺼번에: Select All RTP를 누르면 두 번째 열(probeId)에 값이 있는 모든 행이 들어갑니다.
    • 빼기: Selected RTP에서 행 머리글을 더블클릭하거나, 행을 선택하고 Delete를 누릅니다. 모두 빼기: 표 왼쪽 위 모서리 칸(첫 열 머리글 왼쪽 빈칸)을 더블클릭하고 확인을 누르면 모든 행이 지워집니다(화면에서만 지우며 DB는 바뀌지 않습니다).
    • 셀 고치기: 셀을 선택하고 다시 클릭하거나 F2, 또는 바로 타이핑합니다. Enter 확정, Esc 취소.

  4. 초점(Foci) 또는 인덱스(Indices) 다듬기 — 필요할 때만

    • Selected Foci에 원하는 초점 목록을 입력한 뒤, Selected RTP의 하늘색 머리글 열(azFocusMm) 셀을 더블클릭하면 그 행의 초점이 바뀌고 조리개 크기(azAperSizeMm)와 elevIndex가 자동 계산됩니다. 모든 행에 한 번에 적용하려면 Update All Foc/Aper를 누릅니다.
    • Elev data req?를 켜 두면 Elevation 조리개(elAperSizeMm)도 함께 계산됩니다.
    • Selected Indices에 0 2 4처럼 순번을 입력하고 파라미터 셀을 더블클릭하면, 그 셀의 값 중 해당 순번 값만 남깁니다.
    • Foci와 Indices는 둘 중 하나만 씁니다. 한쪽에 입력하면 다른 쪽은 자동으로 비워집니다.
    자동 계산된 셀은 연어색으로 표시됩니다. f-number와 초점에서 추정한 값이므로 저장 전에 한 번 확인하세요.

  5. 파라미터 확인

    ④ 카드의 Max Sys TxGain, Profile TxGain, Speed of Sound (m/s)(기본 1540)를 확인합니다. 비슷한 기존 레코드에 PulseString만 덧붙이지 않고 새로 만들려면 Create New from MSI =를 체크하고 MSI 범위(to MSI =)를 입력합니다. Chirp 펄스면 NumCycles for Chirp를 채웁니다.

  6. Tank 조건 저장 — Save Tank RTP to DB

    ③ Purpose(기본 RTP; Sample·SSR·FDA·IEC 선택 가능)를 확인하고 누릅니다. 확인 창에서 확인을 누르면 meas_setting에 새 행이 저장됩니다.
    • 새로 만든 measSetId 범위가 SetId Range에 자동으로 채워집니다(예: 3711:3713).
    • 새로 저장된 행이 팝업 표로 보여집니다. 내용을 확인하고 Close. 이미 DB에 있던 조건은 새로 만들지 않으므로 팝업에 나오지 않습니다(8장).

  7. Power 조건 저장 — 준비 → 실행

    Get matched Power MeasSetId: SetId Range의 Tank ID마다 짝이 되는 Power ID를 찾아 MeasInput_YYYYMMDD.txt로 내려받습니다(조회만, 저장 없음).
    Save Power to DB: Selected RTP를 comments='Power' 조건으로 meas_setting에 저장합니다.

  8. (선택) 고른 행을 엑셀로 보관 — Save to Excel

    Selected RTP 표를 원본파일명-Sel.xlsx로 내려받습니다. DB에는 기록하지 않습니다.

5. 온도(Temp) 조건 저장

  1. Selected RTP 준비

    4장 1~3단계처럼 저장할 행을 Selected RTP에 넣습니다.

  2. Temp Options 선택

    목록에서 옵션을 고르면 옵션 설명과 필요한 입력칸 이름이 바뀝니다(직접 타이핑하면 바뀌지 않으니 목록에서 고르세요).

  3. 값 입력

    measTxGain, PulseWidthUsec, 그리고 옵션에 따라 나타나는 칸(FmMHz, azAperElem, Multi-PulseWidthUs, PwCwUseCode 등)을 채웁니다.

  4. Save Temp to DB

    확인하면 temp_setting에 저장되고 새 행이 팝업으로 보여집니다.

  5. (선택) Update Prf from Init

    TempLimit(기본 20)을 확인하고 누르면, 선택한 RTP의 probe에 대해 저장 프로시저 update_Prf_From_Init(probeId, TempLimit)을 실행합니다. 해당 probe의 초기 온도 측정 데이터(temperature)가 있어야 합니다.
옵션설명추가 입력칸
0전압·PulseWidthUs·조리개 조합마다 Freq 대비 초기 온도 시험 세트 생성FmMHz, azAperElem
1Freq·PulseWidthUs·조리개·measVoltage 조합마다 세트 생성Multi-PulseWidthUs(측정한 값 제외), PwCwUseCode
3선택한 Freq·PulseWidthUs·prof.Voltage 조합에 대해 조리개 소자 수별 세트 생성azAperElem, FmMHz
4선택한 PulseWidthUs·조리개·measVoltage 조합에 대해 Freq별 세트 생성FmMHz, azAperElem, PwCwUseCode
14선택한 measVoltage·PulseWidthUs·조리개 조합에 대해 Freq(시작/끝/간격)별 세트 생성Fm: Start/end/step, azAperElem

저장할 때 서버에서 일어나는 일

  1. 로그인·DB 확인 — 로그인한 사용자인지, 선택한 DB가 허용된 업무 DB인지 검사합니다.
  2. 입력 검사 — 표와 입력값의 형식을 확인합니다. 잘못되면 화면에 오류 메시지가 뜨고 아무것도 저장되지 않습니다.
  3. 잠금 — 같은 저장 작업이 동시에 실행되지 않도록 DB 잠금(sp_getapplock)을 겁니다. 다른 사람이 저장 중이면 잠시 기다립니다.
  4. 중복 확인 — 행마다 같은 측정조건이 DB에 이미 있는지 먼저 찾습니다. 있으면 새로 만들지 않고 건너뛰거나 기존 행을 고칩니다(8장).
  5. ID 발급·계산 — 새로 만들 행만 현재 최대 measSetId/tempSetId 다음 번호를 받습니다(probe_info의 소자 정보 사용).
  6. 한 번에 저장 — 모든 행을 하나의 트랜잭션으로 저장합니다. 중간에 오류가 나면 전부 취소(rollback)되어 일부만 저장되는 일이 없습니다.
  7. 결과 반환 — 새 ID 범위, 새로 저장된 행, 고친 measSetId 목록(메시지)을 화면으로 돌려줍니다.
화면에 보이지 않는 값: Total TxGain points(20)와 Meas TxGain Num(12)은 입력칸을 없앴지만, 원본과 같은 기본값으로 계속 함께 저장됩니다.

8. 이미 있는 측정조건은 어떻게 되나요?

요약 — 네, DB에 같은 측정조건이 이미 있으면 새 행을 만들지 않습니다. 다만 저장 종류마다 “같다”의 기준과 처리 방식이 다릅니다.
  • Tank: 새로 만들지 않고 기존 행의 ePulseString·pulseWidthUsec·isPhaseInverse를 보완합니다.
  • Power: 기존 행이 1개면 pulseWidth가 더 클 때만 갱신하고, 2개 이상이면 아무것도 하지 않습니다.
  • Temp: 같은 조건이 있으면 조용히 건너뜁니다.

비교 범위와 Create New from MSI

  • 체크하지 않으면 해당 probe의 모든 기존 레코드와 비교합니다. 예전에 만든 조건이 있으면 재사용·보완됩니다.
  • 체크하면 MSI(~MSI End) 범위 안의 레코드하고만 비교합니다. 그 범위에 없는 조건은 예전에 같은 조건이 있어도 새로 만듭니다. 새 측정 세트를 따로 만들고 싶을 때 쓰세요.
  • MSI가 0(기본값)이면 체크해도 모든 레코드와 비교하므로 체크하지 않은 것과 같습니다. 체크만 하고 MSI를 0으로 두면 아무것도 새로 만들어지지 않습니다.
  • 모두 새로 만들려면 MSI에 현재 가장 큰 measSetId보다 큰 값(예: 최대값 + 1)을 넣습니다. 그러면 기존 레코드가 모두 비교 범위 밖이 되어 새 행으로 추가됩니다. 단, 한 번의 저장 안에서 같은 조건이 두 번 나오면 두 번째는 방금 만든 행과 중복으로 처리됩니다.
  • Tank는 measSetId ≥ MSI, Power는 measSetId > MSI로 비교합니다(원본 VB와 동일).

중복 조건 확인 창 (저장 전)

  • Save Tank / Power / Temp to DB를 누르면 저장하기 전에 DB를 읽기만 하는 사전 검사를 합니다. 같은 조건이 이미 있으면 중복 조건 확인 창이 뜹니다. 중복이 없으면 창 없이 바로 저장합니다.
  • 창의 표에는 Selected RTP 행 번호, 비교한 조건(열 머리글: PMpulseType, FmMHz, FocusPMm 등), 겹친 기존 measSetId, 일반 저장 때 처리 방법(병합 또는 건너뜀)이 나옵니다.
  • 원본대로 저장: 원본 VB와 똑같이 저장합니다. 중복 조합은 병합하거나 건너뛰고, 나머지만 추가합니다.
  • 중복도 새로 입력: 한 번 더 확인한 뒤, 중복 검사 없이 모든 조합을 새 행으로 추가합니다. 기존 행은 바꾸지 않습니다(병합·isPhaseInverse 갱신 없음).
  • 취소: 아무것도 저장하지 않습니다.
  • 사전 검사는 이미 DB에 있는 행과만 비교합니다. 같은 저장 안에서 앞 행이 새로 만들 행과 겹치는 경우는 표에 나오지 않습니다.
  • Temp 저장은 이 옵션과 상관없이 temp_setting 전체와 비교합니다.

결과를 확인하는 방법

  • 새 행 팝업은 이번에 새로 만든 행만 보여 줍니다. 모든 행이 이미 있었다면 팝업이 뜨지 않으며, 오류가 아닙니다.
  • 기존 행을 고친 경우에는 위 메시지에 고친 measSetId가 나열됩니다.
  • Temp는 건너뛸 때 메시지가 없으므로, 팝업에 기대한 행이 없으면 이미 DB에 있는 조건입니다.

10. 자주 묻는 질문·오류

저장했는데 새 행 팝업이 안 떠요.

같은 측정조건이 DB에 이미 있어서 새로 만들 행이 없었던 경우입니다. 메시지에 고친 measSetId가 있는지 확인하세요. 자세한 규칙은 8장을 보세요.

파일 목록이 비어 있어요.

Excel File Directory 입력칸을 더블클릭해 폴더를 고르세요. 폴더 바로 아래에 있는 파일만 목록에 나타납니다.

“Could not find file” 메시지가 나와요.

목록에서 파일을 클릭해 선택한 뒤 Open Excel File을 누르세요. 창을 새로 열었다면 폴더를 다시 골라야 합니다.

“Please fill in SetId Range!” 메시지가 나와요.

Get matched Power MeasSetId는 SetId Range가 필요합니다. 먼저 Save Tank RTP to DB를 실행하거나 3711:3720 형식으로 직접 입력하세요.

“Please Select Options or add values…” 메시지가 나와요.

Save Temp to DB 전에 Temp Options를 목록에서 고르고, 옵션에 따라 나타나는 입력칸을 채우세요. 지원 옵션은 0·1·3·4·14입니다.

“No initial temp data in database.” 메시지가 나와요.

Update Prf from Init은 해당 probe의 초기 온도 측정 데이터가 DB에 있어야 실행됩니다. Selected RTP에 해당 probe 행이 있는지도 확인하세요(“Please select one RTP!”).

저장 중 오류가 났는데 일부만 저장됐을까요?

아닙니다. 저장은 하나의 트랜잭션이라 오류가 나면 전체가 취소됩니다. 메시지를 확인하고 고친 뒤 다시 저장하세요.

창을 닫으면 작업 내용은요?

Exel Input과 Selected RTP는 저장되지 않습니다. 필요하면 닫기 전에 Save to Excel로 내려받아 두세요.
